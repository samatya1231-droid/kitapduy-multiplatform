# Font assets

Source: Google Fonts upstream `ofl/inter` and `ofl/playfairdisplay`.

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Inter: static instances at weights 300, 400, 500, 600, 700, 900; optical size 14.
Playfair Display: static instances at weights 400, 500, 600, 700, 900.
The derived serif font's internal family name is `KitapDuy Serif` to respect the
reserved upstream name. Glyph outlines are unchanged; weight axes are instantiated.
All 11 fonts were checked for Turkish İıŞşĞğÇçÖöÜü characters.

The SIL OFL license files are also included in the application's Compose resource
files/font_licenses directory. Fonts are bundled for offline use on both platforms.

Source files were downloaded on 26 September 2026. Conversion uses fonttools 4.66.0.
